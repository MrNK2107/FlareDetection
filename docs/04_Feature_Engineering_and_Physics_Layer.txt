FEATURE ENGINEERING & PHYSICS LAYER - PHASES 2 & 3
Aditya-L1 Solar Flare Forecasting System
=============================================

Feature engineering is where this system will separate itself from baseline
approaches. Implement features in layers. Validate each layer independently
before adding the next.

PHASE 3 - PHYSICS-AWARE FEATURE LAYER
--------------------------------------

This layer encodes solar physics domain knowledge as additional features. The
goal is not to hardcode rules, but to give the model informative inputs that
it might not discover from raw data alone.


3.1 STAGE INDICATORS

  soft_rising (binary):
    = 1 if dSoft/dt > threshold for 3 consecutive windows.
    Threshold = 95th percentile of dSoft/dt in quiet-Sun baseline.

  hard_accelerating (binary):
    = 1 if d2Hard/dt2 > threshold for 2 consecutive windows.
    Threshold = 95th percentile of d2Hard/dt2 in quiet-Sun baseline.

  precursor_candidate (binary):
    = 1 if soft_rising AND hard_flux < 1.5 * hard_quiet_baseline.


3.2 DERIVED RATIOS

  thermal_fraction:
    soft_flux / (soft_flux + hard_flux)
    Smoothed over 30 seconds.

  nonthermal_index:
    rate of change of hard_flux relative to soft_flux:
    (dHard/dt) / (dSoft/dt + epsilon)
    where epsilon is a small constant to avoid division by zero.


3.3 HISTORICAL CONTEXT

  time_since_last_flare (seconds):
    Time elapsed since the last flare event (from GOES catalogue).
    Solar active regions often produce repeated events.

  cycle_phase_proxy (float [0, 1]):
    Current solar cycle phase: day-of-cycle normalized to [0, 1] using
    estimated solar maximum date. 0 = solar minimum, 1 = solar maximum.
