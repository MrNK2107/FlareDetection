2. INFERENCE API SPECIFICATION

  Framework: FastAPI + Uvicorn (with async WebSocket support)

  Endpoints:

    GET  /health
    Description: Health check endpoint. Returns model loaded status.

    POST /predict
    Description: Single window prediction.
    Input: Feature vector (20-minute window of soft + hard flux).
    Output: Full inference payload (see Evaluation Framework document).

    GET /metrics
    Description: Returns current evaluation metrics.

    WS /ws/stream
    Description: WebSocket for real-time streaming of predictions to
                 dashboard. Server pushes inference payloads every 10
                 seconds (or at configurable cadence).


3. FRONTEND SPECIFICATION

  Framework: React (functional components, hooks)
  Charts: Recharts
  UI Components: shadcn/ui

  Dashboard Pages:
    - Real-Time View (default): live plot, gauge, state indicator
    - Historical View: 30-day timeline, hindcast overlay, CSV export
    - Settings: alert thresholds, quiet window duration, API config

  WebSocket Integration:
    - Automatic reconnection with exponential backoff
    - Connection status indicator in header
    - Fallback to polling if WebSocket fails
